Two-Step Knowledge Distillation for Tiny Speech Enhancement
ICASSP 2024
Rayan Daod Nathoo*, Mikolaj Kegler*, Marko Stamenovic (Bose Corporation, USA)

The Two-Step framework decouples representation learning from target imitation: a first distillation stage injects latent geometric structure into a sub-100k-parameter causal student via a Similarity-Preserving loss, before a second stage fine-tunes against raw regression targets, directly addressing the data-scarcity problem intrinsic to streaming-constrained deployment environments. This staged separation allows the student to inherit a rich internal representation space independently of output supervision, yielding consistent gains over single-stage distillation baselines at sub-100k parameter budgets and under adverse low-SNR operating conditions where conventional distillation collapses.

AI-based telepresence for broadcast applications
SPIE Applications of Digital Image Processing XLV, San Diego, USA · Aug 22, 2022
Henrique Piñeiro Monteagudo, Rayan Daod Nathoo, Laurent Deillon, Gao Changsheng, Touradj Ebrahimi (MMSPG, EPFL, Lausanne, Switzerland)

Introduces a real-time GPU pipeline that composites remote webcam participants into a TV studio by chaining learning-based background matting with super-resolution upscaling before merging with host video. Deployed in the AdMiRe mixed-reality project, the system sustains ≥25 fps and validated positively in both objective and subjective broadcast trials.

Personalised Audio Enhancement
Master's Thesis, Swiss Federal Institute of Technology Lausanne (EPFL)
Rayan Daod Nathoo (EPFL, Lausanne, Switzerland)

Adapted from a causal VoiceFilter speech-separation architecture, the proposed system conditions time-frequency mask estimation on jointly trained class embeddings rather than speaker d-vectors, enabling users to select which audio event to extract from a mono mixture in real time. Training relies on GPU-accelerated dynamic mixing that continuously synthesises background–foreground pairs with random SNR, chunk placement, and adversarial only-background examples, so the model responds only when the requested event is present. Focused on footstep manipulation in gaming, the separator reaches 9.82 dB SI-SDR on six-second synthetic mixtures and transfers with promising but imperfect results to real gameplay recordings; the same architecture generalises to 41 FSD Kaggle event classes with 9.81 dB SI-SDR on four-second two-event mixtures, demonstrating that personalised, causal audio scene customisation is feasible within tens of milliseconds of CPU inference latency.
